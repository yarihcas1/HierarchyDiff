# HierarchyDiff

2つの GameObject とその子階層を比較し、コンポーネントのプロパティ差分を一覧表示・コピーできる Unity エディタ拡張です。
プレファブのバリエーション間の設定差分の確認や、アバター・ワールドのオブジェクト間での設定の移植などに使えます。

## 動作環境

- Unity 2022.3 以降

## 導入方法

`Assets/Editor/HierarchyDiff.cs` を、お使いのプロジェクトの任意の `Editor` フォルダにコピーしてください。

## 使い方

1. メニュー **Tools > yarihcas1_lab > Hierarchy Diff** からウィンドウを開きます。
2. 「オブジェクト A」「オブジェクト B」に比較したい GameObject を指定します。
3. 子オブジェクトは名前で対応付けられ、階層ごと・コンポーネントごとに差分が表示されます。
4. 各行の **A→B** / **B→A** ボタンで値をコピーできます。

## 主な機能

- **階層の比較**: 子オブジェクトを名前で照合し、片方にしか存在しないオブジェクトやコンポーネントを警告表示します。
- **プロパティ単位の差分表示**: SerializedProperty を用いて、コンポーネントの各プロパティ値を比較します。
- **コピー**: プロパティ単位のほか、コンポーネント単位・階層ノード単位・全体（「全て A→B」「全て B→A」）での一括コピーに対応しています。コピー操作は Undo で元に戻せます。
- **フィルター**: コンポーネント名・プロパティ名で表示を絞り込めます。
- **全て展開 / 全て折りたたむ**: 階層の折りたたみを一括で切り替えます。

### オプション

| オプション | 説明 |
|---|---|
| 参照の違いを無視 | 同じ名前・同じ相対パスのオブジェクトを指す参照は同一とみなします |
| 参照を自動リマップ | コピー時、オブジェクト参照をコピー先の階層内の同じ位置にあるオブジェクトに自動変換します |
| 差分のない階層を非表示 | 差分を含む階層のみを表示します |

## 注意事項

- 一括コピーを行う前に、プロジェクトのバックアップを取ることをおすすめします。
